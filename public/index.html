Cómo funciona

El bot escucha por Telegram (texto y fotos) a los usuarios autorizados. Cada mensaje se lo pasa a un modelo de IA (Claude) junto con las reglas del negocio y una lista de "herramientas" que puede usar para leer o modificar la base de datos. Vos le contás lo que pasó en lenguaje normal, y el modelo decide qué acción ejecutar (o qué preguntarte si falta un dato importante). El panel web y el chat comparten exactamente la misma base — lo que carga uno lo ve el otro al instante.

Si el bot se queda repitiendo el mismo error con alguien, esa persona puede mandarle /reiniciar por Telegram: le borra la memoria de esa charla puntual (nunca los datos de ventas, stock, etc.) y sigue funcionando normal.
